Helping with: Loops in Python

My loop prints 0 to 4, but I want 1 to 5.

for i in range(5):
    print(i)

Hint 1 Look at where range() starts counting. What's the first number it gives you?

Hint 2 range() can take two numbers: where to start and where to stop. The stop number is never included.

Hint 3 Try range(1, ...). Which stop number makes the last value 5?
